# 2fa-voting-system

A secure voting system with Two-factor authentication using QR codes and TOTP.

##Teckstack
- Python
- Flask
- SQLite
- React
- Google Authentication / TOTP

##Current Backend
The current backend implements:
- User Registration
- Password Hashing
- Login
- Two-factor Authentication
- QR code generation
- TOTP verification
- Session Management
- Role-based Authentication
- Account lockout
- Security audit and Logging

##Running the Backend
install dependencies:
pip install -r requirements.txt

Run:
python app.py

The Flask backend runs on:
http://127.0.0.1:5000
